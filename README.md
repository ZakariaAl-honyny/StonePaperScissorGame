<h1 align="center" id="title">Stone Paper Scissor Game</h1>

<h2>🚀 Overview</h2>
The ** Stone Paper Scissor Game ** is a console application that you can play with your computer from 1 to 10 roundes, check if your answer is correct or not, print result each round, and in th end print final results for your game.

<h2>🌳 Project files and directories</h2>

- the `Core` directory is contains the core libraries/classes in this system.
  
- the `Lib` directory  is contains the global libraries/classes, you can use in any system.

- the `Screen` directory is contains all screens in this system.

- the `Source.cpp` is the main file and content the main function in this project.
